# Анализ результатов маркетинговой кампании и оценка реагирования клиентов на рассылку 📈📩

Проект посвящен продуктовой и маркетинговой аналитике, статистическому анализу эффективности различных шаблонов сообщений (A/B-тестирование) и исследованию конверсий воронки в разрезе демографических сегментов.

### 🎯 Бизнес-задача
Сравнить два макета рассылки (Шаблон А и Шаблон Б), оценить вовлеченность и лояльность пользователей на каждом этапе воронки, выявить статистически значимые различия в поведении сегментов и сформировать рекомендации по запуску перспективных кампаний.

### 🛠 Технологический стек
* **Язык программирования:** Python
* **Библиотеки анализа данных:** Pandas, NumPy, SciPy (проведение Z-теста для пропорций)
* **Визуализация:** Matplotlib, Seaborn (построение матриц корреляции по шкале Чеддока, воронки событий)
* **Среда разработки:** Jupyter Notebook / Google Colab

### 🚀 Ключевые этапы исследования
1. **Общий обзор и сегментация выборки:** Разделение клиентской базы по возрасту (до 28 лет, 28–40 лет, 40+ лет) и гендерному признаку для детального когортного анализа.
2. **Анализ воронки конверсий:** Сквозной расчет переходов по этапам: `отправлено` ➡️ `доставлено` ➡️ `открыто` ➡️ `переход_по_ссылке` / `отписка`.
3. **Статистическое тестирование (A/B-тест):** Проведение Z-тестов для оценки значимости различий в долях доставленных писем, открытий и переходов между тестовыми группами.
4. **Корреляционный анализ:** Построение матрицы корреляций событий для выявления взаимосвязей на различных шагах воронки.

### 📈 Результаты и выводы
* **Заинтересованность и конверсия:** Клиенты с шаблоном А в 1.5 раза чаще открывали доставленные сообщения. Несмотря на то, что открывшие шаблон Б чаще кликали по ссылке, общая конверсия из доставки в клик у группы Б оказалась почти на четверть ниже, чем у А.
* **Лояльность и отписки:** Шаблон А провоцирует отписки в 1.5 раза чаще (относительно доставленных). При этом статистически значимая разница в отписках относительно открытых писем отсутствует для большинства когорт, кроме сегмента "Мужчины, 28–35 лет".
* **Качество данных:** У группы Б доля доставленных сообщений оказалась вдвое выше (80% против 39%), что указывает на значительную разницу в актуальности контактных данных между выборками и подтверждено статистическим тестом (p-value = 0.0).

### 📋 Ключевые рекомендации
* **Оптимизация макетов:** Доработать шаблон А (сильные стороны темы и первых строк которого дают высокую открываемость), внедрив в него удачные элементы призыва к действию (CTA) из шаблона Б для подтягивания кликабельности.
* **Стратегия запуска:** До доработки макетов использовать шаблон А как основной для всех клиентских сегментов.
* **Гигиена данных:** Провести масштабную актуализацию и очистку контактных данных клиентов, а также настроить их регулярное обновление на постоянной основе.
